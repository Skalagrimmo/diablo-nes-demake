## Implementation focus

Treat this as a fresh independent task. Use only the supplied baseline archive and shared brief as the project inputs; do not rely on assumptions about how the baseline was authored or on any previous conversation.

Build a coherent playable evolution, not just a list of proposed features. Preserve the strongest baseline gameplay values while establishing a distinct identity for The Last Reactor.

Prioritize:
- atmosphere communicated through level layout, silhouettes, animation, lighting and sound rather than decorative text alone;
- readable class/character differences;
- enemies with different tactical behaviours;
- a useful reward and equipment loop;
- a mechanism or powered route that makes the industrial setting interactive;
- a memorable boss/major encounter;
- robust mobile input and save/continue.

Keep implementation scope realistic. If output or context limits prevent a full campaign, complete one polished district and its entire gameplay loop first. Do not leave placeholder systems presented as finished features.
