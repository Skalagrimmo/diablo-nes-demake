# Перевірка прототипу

Цей документ — ручний smoke-test checklist для перевірки збірки перед публікацією або злиттям змін.

**Важливо:** наявність пунктів у цьому списку не означає, що вони вже пройдені. У репозиторії наразі немає автоматизованого тестового набору для геймплею. CI перевіряє синтаксис JavaScript та наявність основної документації, але не замінює запуск гри.

## 1. Запуск

- [ ] Відкривається титульний екран без помилок.
- [ ] Після взаємодії користувача запускається звук.
- [ ] Перехід до вибору класу працює.
- [ ] Можна вибрати кожен із трьох класів і почати новий забіг.

## 2. Керування та переміщення

- [ ] Стрілки та WASD керують рухом.
- [ ] Рух по діагоналі працює коректно.
- [ ] Персонаж не проходить крізь стіни.
- [ ] Атака та зілля працюють.
- [ ] Взаємодія біля сходів працює.
- [ ] Пауза, відновлення гри й перемикання звуку працюють.

## 3. Класи та бій

- [ ] Warrior завдає ближньої шкоди й відкидає противників.
- [ ] Rogue атакує ножами; допоміжне наведення не заважає ручному керуванню.
- [ ] Sorcerer використовує вогняну кулю; ефект горіння працює.
- [ ] Противники пересуваються та атакують.
- [ ] Смерть і відновлення на поточному поверсі працюють.

## 4. Кампанія

- [ ] Переходи між поверхами 1–6 працюють.
- [ ] Генерація не створює заблокованого шляху до сходів на звичайних поверхах.
- [ ] На третьому поверсі запускається бій із М'ясником.
- [ ] Після М'ясника працює сцена каменя душі й перехід на четвертий поверх.
- [ ] На шостому поверсі з'являється Diablo.
- [ ] Після фінального бою запускається кінцівка.

## 5. Предмети та збереження

- [ ] Золото, зілля та предмети можна підбирати.
- [ ] Підібране спорядження з'являється в інвентарі.
- [ ] Екіпірування змінює характеристики персонажа.
- [ ] Предмет можна продати.
- [ ] Повний інвентар не знищує предмет, який не вдалося підібрати.
- [ ] Після перезавантаження сторінки можна продовжити збережений забіг.
- [ ] Пауза та вихід до титульного екрана не пошкоджують збереження.

## 6. Сенсорний пристрій

- [ ] Екранні кнопки з'являються на сенсорному або вузькому екрані.
- [ ] D-pad керує рухом.
- [ ] A, B і ACT виконують відповідні дії.
- [ ] INV і кнопка паузи працюють.
- [ ] START і CONT працюють на відповідних екранах.
- [ ] Кнопки не блокують прокручування або взаємодію з іншою частиною сторінки ненавмисним чином.
