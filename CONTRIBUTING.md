# Внесення змін

Дякуємо за інтерес до DIABLO — NES DEMAKE. Це невеликий браузерний прототип, тому зміни бажано робити вузькими, перевірюваними й документованими.

## Поточний технічний формат

- Гра міститься в одному автономному файлі index.html.
- Використовуються HTML, CSS, ванільний JavaScript, Canvas 2D та Web Audio API.
- Немає збирача, менеджера пакетів або обов'язкових сторонніх залежностей.
- Поточна архітектура є свідомим форматом прототипу; великий рефакторинг потрібно спочатку узгодити.

## Робочий процес

1. Створіть окрему гілку для зміни.
2. Перед редагуванням перегляньте README.md та документи в docs/.
3. Зберігайте зміни в межах однієї зрозумілої задачі.
4. Перевірте синтаксис і запустіть гру в браузері.
5. Для змін ігрової логіки пройдіть відповідні пункти з [ручного чекліста](docs/testing.md).
6. Оновіть документацію, якщо поведінка, керування або структура справді змінилися.
7. Створіть Pull Request із коротким описом змін і фактичних перевірок.

## Правила сумісності

- Не видаляйте підтримку старих збережень без явної міграції. Поточний формат забігу — v2; завантажувач також приймає v1.
- Не змінюйте формат збереження без перевірки старого й нового сценаріїв.
- Не додавайте сторонні бібліотеки, шрифти або ресурси без пояснення, навіщо вони потрібні.
- Для нових зовнішніх ресурсів зафіксуйте джерело та умови використання.
- Не додавайте токени, ключі API, приватні дані або локальні конфігурації.
- Не заявляйте, що тест пройшов, якщо гру фактично не запускали.

## Повідомлення про зміни

У Pull Request вкажіть:

- мету зміни;
- основні файли, які змінено;
- очікувану поведінку;
- що було перевірено;
- відомі обмеження або проблеми.
