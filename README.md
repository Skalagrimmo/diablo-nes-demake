# DIABLO — NES DEMAKE

**Демейк Diablo (1996) під залізо NES.** Не ремейк у бік більшої деталізації, а чесний «портувальний» експеримент у зворотний бік: що станеться з грою Blizzard North, якщо прогнати її крізь обмеження Famicom/NES 1983 року — 6502 @ 1.79 МГц, 2 KB RAM, 256×240, 4 палітри по 3 кольори, 5 аудіоканалів.

Грається повністю: катсцени в стилі Ninja Gaiden, вибір класу, процедурні підземелля на сідованому генераторі, радіус світла, М'ясник, фінальний твіст.

## Як грати

Відкрийте `index.html` у будь-якому браузері (без залежностей, ванільний JS, один файл).

## Що всередині (і чому саме так)

- **256×240, тайли 16×16** — внутрішній рендер розміру PPU, апскейл із `image-rendering: pixelated`.
- **Радіус світла через «attribute table»** — затемнення виконується по тайлових зонах 16×16 з 4 рівнями, плюс мерехтіння факелів і окреме світло від fireball. Це прямий аналог того, як на NES робили б динамічне світло зміною палітр у attribute table.
- **Процедурна генерація** — кімнати + L-подібні коридори + петля на сідованому mulberry32 RNG: усе, що NES робила б на 6502. Кожен забіг — новий сід.
- **Катсцени Ninja Gaiden** — летербокс, фейк-зум трьома кадрами (двері → двері відчиняються → ВЕЛИКИЙ план очей), текст друкарською машинкою з бліпами, удар серця шумовим каналом. Фінальний твіст оригінала (камінь душі) — стримано: пікселі + треугольний дрон.
- **5 каналів NES-аудіо** — квадратні осцилятори (2 pulse), треугольний бас, шум (удари, двері, серцебиття), все синтезується WebAudio на льоту. Тема меню — омаж Tristram Метта Уелмена.
- **Палітрова заміна** — три класи (Warrior/Rogue/Sorcerer) — це один спрайт із різним кольором туніки, класика NES.

## Ієрархія поверхів

- **B1–B2** — Собор і Катакомби: Fallen, кажани, скелети, зілля, золото, сходи вниз.
- **B3** — Лігво М'ясника: арена з колонами, кров на підлозі, бос-файт, після перемоги — камінь душі.
