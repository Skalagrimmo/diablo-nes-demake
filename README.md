# DIABLO — NES DEMAKE

Фанатський браузерний демейк першого **Diablo (1996)**, переосмислений через естетику та ігрові обмеження 8-бітної епохи. Це не буквальний порт оригіналу й не емулятор NES, а самостійний ігровий прототип із низькою роздільністю, процедурними підземеллями, класами персонажів і короткою кампанією.

> **Стан проєкту:** іграбельний прототип. Основна гра запускається без сторонніх бібліотек і збирача.

## Що вже реалізовано

- Внутрішній ігровий екран **256×240** із піксельним масштабуванням.
- Топ-даун підземелля на картах **40×36 тайлів**; розмір ігрового тайла — 16×16.
- Сідована процедурна генерація кімнат, коридорів, декорацій і розташування об'єктів.
- Шість тематичних поверхів: Cathedral, Catacombs, Butcher Lair, Ancient Crypt, Frozen Halls і Hellfire.
- Три класи: Warrior, Rogue і Sorcerer — з різним здоров'ям, швидкістю та бойовими прийомами.
- Противники, бос М'ясник на третьому поверсі та Diablo на шостому.
- Досвід, рівні персонажа, золото, зілля, випадковий лут та екіпірування.
- Інвентар на 12 предметів і три слоти екіпірування: зброя, броня та амулет.
- Пауза, перемикання звуку, перезапуск поверху, збереження й продовження.
- Автозбереження в браузері та підтримка попереднього формату збереження.
- Синтезована через Web Audio музика й звукові ефекти.
- Сенсорне керування для телефонів і планшетів.

## Запуск

Залежностей, менеджера пакетів або етапу компіляції немає.

**Варіант 1 — відкрити напряму:** відкрийте **index.html** у сучасному браузері.

**Варіант 2 — локальний HTTP-сервер (рекомендовано для перевірки збережень):**

~~~bash
python -m http.server 8000
~~~

Після запуску відкрийте **http://localhost:8000**.

Першу взаємодію з грою виконайте кліком, натисканням клавіші або сенсорної кнопки: браузер може вимагати жест користувача перед відтворенням аудіо.

## Керування

### Клавіатура

| Клавіші | Дія |
|---|---|
| Стрілки або WASD | Рух у восьми напрямках |
| Z або Space | Атака / основна дія |
| X | Використати зілля |
| E | Взаємодія |
| Enter | Підтвердити, почати гру або продовжити сцену |
| ← / → або A / D | Вибір класу |
| I | Відкрити або закрити інвентар |
| P або Esc | Пауза / повернення з паузи |
| M | Увімкнути або вимкнути звук |
| C | Продовжити збережений забіг із титульного екрана |

### Інвентар

Стрілки або WASD переміщують вибір. Enter, Z або Space екіпірують вибраний предмет. X продає вибраний предмет за частину його вартості. Esc або I закривають інвентар.

### Сенсорне керування

На пристроях із сенсорним введенням або вузьким екраном показуються кнопки напрямку, A, B, ACT, START, CONT, INV і паузи.

## Технології та архітектура

- HTML, CSS і ванільний JavaScript.
- Canvas 2D для рендерингу.
- Web Audio API для програмного синтезу музики й ефектів.
- localStorage для локального збереження прогресу та налаштування звуку.
- Один автономний **index.html**; зовнішні бібліотеки й завантажувані ігрові асети не потрібні.

Поточна однофайлова архітектура свідомо збережена як проста база прототипу. Поділ на модулі або перенесення окремих підсистем у WebAssembly / нативний Android-код — можливі напрями майбутніх експериментів, а не вимоги поточної версії.

## Важливі межі поточної версії

- Це **браузерна гра**, а не готовий NES ROM і не емуляція апаратури NES.
- Обмеження NES використані як художній і дизайнерський орієнтир; Web Audio не є точним відтворенням NES APU.
- Гра одиночна; мережевої гри та хмарного збереження немає.
- Прогрес зберігається локально в браузері. Він не синхронізується між пристроями чи різними браузерами.
- Поточна кампанія має шість поверхів і не відтворює повний обсяг оригінального Diablo.
